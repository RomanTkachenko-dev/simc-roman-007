# Два кроки за вечірньою розмовою з Біллом, 16.09.2026

## 1. Пробне підсилення фазового простору

`step1_phase_boost_linear.png` і `step1_phase_boost_log.png`:
зважені 2π (legacy xphsp) та 3π додатково помножено на 10^10 кожний.
Решта кривих, чорна Pythia та всі попередні множники залишені незмінними.
Отже, для 2π зберігається також попередній ×4; для 3π — попередній ×1.
Це демонстраційне масштабування, не фізичне нормування.

## 2. Фіт сімома шаблонами

`step2_seven_channel_fit.png` і `step2_seven_channel_fit_log.png`:
Pythia описується сумою семи гістограм із незалежними невід'ємними
коефіцієнтами. Форма, положення та ширина кожного шаблону не змінюються.
Під графіком показано Pythia мінус фіт у тих самих умовних одиницях.
Немає згладжування, додаткового полінома чи прихованого фону.

Застосовано принцип `fun_sim_total` з коду Білла:
https://github.com/billlee77/omega_analysis/blob/master/fitting_functions.C
Додано φ та окремий 3π-шаблон до його п'ятикомпонентної схеми.

Фіт НЕ використовує старі ручні відносні множники або множник 10^10
із кроку 1. Кожен початковий шаблон поділено на його інтеграл лише для
числової стійкості. Потім його амплітуду визначено з Pythia.
Це математично еквівалентно множенню початкової гістограми на вільний масштаб.

Фітуються незважені лічильники Pythia `Background/mx` після cuts.
У цьому дереві немає гілки Weight. Діапазон 0–2 GeV, 100 бінів по 0.02 GeV.
Усі 100 бінів залишено, включно з бінaми, у яких жоден SIMC-шаблон не має подій.
Underflow/overflow виключено з фіту й записано в `summary.json`.

Мінімізується сума квадратів різниць із дисперсією, рівною кількості подій
Pythia в біні; для порожніх бінів використано дисперсію 1.
Оптимум отримано невід'ємним лінійним методом найменших квадратів (NNLS)
та незалежно перевірено ROOT Minuit2. Збережено ROOT fit result.
Однаковий попередній display-множник застосовано до Pythia і результату
лише для відображення; він не впливає на знайдені амплітуди.

## Ваги та обмеження

- ω, 2π, 3π: оригінальна Weight.
- φ, ρ, η, η′: незважені шаблони кількості подій, як у попередньому графіку.
  Проблемні від'ємні ваги не виправляли, не брали за модулем і не застосовували.
- Це попередній змішаний template fit, а не повністю зважена фізична сума.
- Визначення Pythia mx ще потрібно підтвердити як еквівалент SIMC missmass.
- На канал є лише 1000 збережених SIMC-подій до аналізових cuts.
  Фіт вважає форми фіксованими й не враховує їхню скінченну MC-статистику.
- Наведені похибки коефіцієнтів умовні: лише за похибками Pythia, без
  невизначеності шаблонів, моделей, нормування та систематик.
  Для коефіцієнтів на нульовій межі симетричну похибку не наведено.
- Успішна мінімізація не означає доброго опису даних. Перевіряйте залишки
  та показник chi2 у summary.json. Номінальне ndf=100−7=93 наведено довідково;
  наявність граничних параметрів і невраховані похибки шаблонів обмежують його трактування.
- Коефіцієнти — діагностичні внески у кількість Pythia-подій, не перерізи
  та не підтверджені фізичні виходи каналів.

## Cuts — однакові для Pythia та SIMC

```
abs(hsdelta)<8.0 && abs(hsxptar)<0.080 && abs(hsyptar)<0.035
&& ssdelta>-10.0 && ssdelta<22.0
&& abs(ssxptar)<0.040 && abs(ssyptar)<0.024
```

## Файли й відтворення

- Графіки: PNG та PDF із однаковими назвами.
- `results.root`: початкові/нормовані шаблони, крок 1, компоненти фіту,
  сума, Pythia, залишки, ROOT fit result, canvases і metadata.
- `fit_coefficients.txt`: результати для кожного каналу, зокрема масштаб
  відносно початкової гістограми та відносно попередньої кривої.
- `summary.json`: коефіцієнти, якість мінімізації, обмеження, SHA256 і перевірки.
- Код у батьківській папці: `fit_seven_templates.py`, `fit_seven_templates.C`,
  `fit_seven_templates.sh`.

Початковий запуск із PowerShell:

```
wsl.exe -d Ubuntu -- /mnt/d/EIC/eic-shell -- /mnt/d/EIC/SIMC_RUNS/ACPOSTUMA_SIMC_GFORTRAN/fit_seven_templates.sh
```

Захист від перезапису: якщо `results.root` уже є, повторний запуск зупиняється.
Для нового результату всередині eic-shell запустіть Python-код із
`--output /mnt/d/EIC/SIMC_RUNS/ACPOSTUMA_SIMC_GFORTRAN/нова_папка`.
Початкові ROOT-файли та всі старі графіки збережені без змін.

## Отриманий результат

ROOT Minuit2 завершився зі статусом 0 та covariance status 3.
Його мінімум узгодився з незалежним NNLS: chi2=874426.1773.
Номінальне chi2/93 ≈ 9402 (лише похибки Pythia, без MC-похибок).
Отже, це НЕ статистично задовільний опис у використаній моделі похибок,
хоча масштабований 3π дає великий внесок у широкий фон.
Найпомітніші залишки видно поблизу ω та в області 1.0–1.2 GeV.

Додаткові множники відносно кривих попереднього частково зваженого графіка
(не відносно кроку 1):

| Канал | Множник фіту відносно попередньої кривої |
|---|---:|
| ω | 1.5332678 × 10^7 |
| φ | 1.337547 |
| ρ | 0.599060 |
| η | 0.279904 |
| η′ | 0 — нижня межа |
| 2π | 3.0486776 × 10^11 |
| 3π | 6.8879045 × 10^12 |

Нуль η′ означає лише, що при цих шаблонах, межах і критерії фіту оптимум
досяг нижньої межі. Це НЕ доказ відсутності η′ у фізичному процесі.
Дванадцять бінів із 42610 Pythia-подіями взагалі не покриті цими MC-шаблонами;
їх не видаляли з фіту. Потрібні більша MC-статистика, узгоджені ваги всіх
каналів і перевірка визначення маси/фізичної відповідності вибірок.
