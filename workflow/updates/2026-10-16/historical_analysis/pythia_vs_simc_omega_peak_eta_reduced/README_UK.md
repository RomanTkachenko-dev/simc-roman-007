# Оновлення: η /1,5 та яскраво-червона сума

Порівняно з попередньою папкою `pythia_vs_simc_omega_peak` лише η додатково поділено на 1,5. Підсумкові відносні коефіцієнти: ω ×1, φ /10, ρ ×2, η /22,5, η′ /15, X-phase-space ×4. Спільний коефіцієнт нормування за ω і шкалу Pythia збережено. Суму перераховано з усіх шести компонентів, колір — яскраво-червоний (#FF0000).

Висоти сумарного SIMC та Pythia у біні 0,78–0,80 ГеВ залишилися однаковими: 4,2132258407 ГеВ⁻¹. Площа SIMC на шкалі графіка тепер 0,6671648791, площа Pythia — 1. Це емпіричне нормування за піком, не за світністю. Використано raw-count гістограми без event Weight. Інтерпретація Pythia mx як reconstructed missing mass залишається припущенням до підтвердження автором файлу.

`omega_peak_matched_channels.png/pdf` містить компоненти, суму та Pythia. `omega_peak_matched_totals.png/pdf` — лише суму і Pythia. `omega_peak_matched_count_comparison.png/pdf` — шкалу початкових відліків Pythia. Гістограми та полотна збережено в `omega_peak_matched.root`, подробиці перевірок — у `summary.json`. Попередні результати не змінено.

Повторний запуск із PowerShell:

```powershell
wsl.exe -d Ubuntu -- /mnt/d/EIC/eic-shell -- /mnt/d/EIC/SIMC_RUNS/ACPOSTUMA_SIMC_GFORTRAN/refine_eta_red_sum.sh
```

Скрипт щоразу читає попередню незмінену версію, тому повторний запуск не зменшує η накопичувально.
