# SIMC із Weight після acceptance cuts

Гістограми заново побудовано з шести дерев h10. Кожна подія, що проходить cuts, додає до відповідного біна своє значення Weight зі збереженням знака. Це еквівалентно заповненню ROOT із selection `Weight*(cuts)`. Похибки обчислено через суму квадратів ваг. Результат перевірено по кожному біну та його похибці проти раніше збережених weighted-гістограм.

```text
abs(hsdelta)<8.0 && abs(hsxptar)<0.080 && abs(hsyptar)<0.035
&& ssdelta>-10.0 && ssdelta<22.0
&& abs(ssxptar)<0.040 && abs(ssyptar)<0.024
```

Після заповнення застосовано поточні коефіцієнти: ω ×1, φ /10, ρ ×2, η /22,5, η′ /15, X-phase-space ×4. Сума — яскраво-червона. Ваги не замінювали на абсолютні значення, від’ємні події не відкидали.

## Результат перевірки

Від’ємні ваги після cuts: φ — 536 із 549; ρ — 569 із 573; η — 584 із 584; η′ — 583 із 591. Для ω та X-phase-space від’ємних ваг немає.

Сумарний weighted SIMC від’ємний у всіх бінах області 0,70–0,86 ГеВ. Навіть максимальний бін у цій області, 0,78–0,80 ГеВ, дорівнює −1,0852161959 × 10⁻⁵. Тому нормування сумарного спектра до додатного піка Pythia не виконано: воно потребувало б від’ємного множника й перевернуло б знаки всіх каналів. Попередній коефіцієнт для raw counts тут також не застосовано.

Це діагностичний результат, не підтверджений фізичний вихід подій. Необхідно з’ясувати походження та допустимість знаків Weight для цих каналів у поточній конфігурації SIMC; сам факт від’ємних ваг не встановлює причини. Pythia Background не має гілки Weight; її вхідна гістограма збережена окремо в ROOT, але нормованого накладання не створено.
