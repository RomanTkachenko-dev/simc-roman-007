# Спільні графіки відновленої missing mass

Склад: omega, phi, rho, eta, eta-prime та upstream X-phase-space. Використано збережені гістограми `missmass` із ROOT-результатів після SIMC; генерацію не повторювали, фізичні моделі не змінювали.

## Основні графіки після cuts

- `missing_mass_overlay_raw_after.png` — шість незважених розподілів на одній системі осей.
- `missing_mass_sum_raw_after.png` — кольорові внески, складені один над одним; чорна лінія — їхня сума.
- `missing_mass_overlay_weighted_after.png` — накладання розподілів зі збереженими signed Weight.
- `missing_mass_sum_weighted_after.png` — алгебраїчна сума зважених розподілів, включно з від'ємними внесками.

Для кожного файла є PDF. Варіанти `before` — до додаткових analysis cuts, але теж після SIMC. Не плутати їх із генераторним рівнем до проходження установки.

Однакове бінування: 100 стовпчиків від 0 до 2 GeV, ширина 0.02 GeV. Однакові cuts для всіх каналів:

```cpp
abs(hsdelta)<8.0 && abs(hsxptar)<0.080 && abs(hsyptar)<0.035
&& ssdelta>-10.0 && ssdelta<22.0
&& abs(ssxptar)<0.040 && abs(ssyptar)<0.024
```

До cuts: 6000 записів, 5992 у показаному діапазоні і 8 в underflow (M<0).
Після cuts: 3415 записів, 3414 у показаному діапазоні і 1 в underflow. Негативні missing mass не перетворювалися на додатні.

**Це сума тестових вибірок, не передбачення фізичного сумарного виходу.** Для кожного каналу множник дорівнює 1. Не застосовано ні відносної нормалізації каналів, ні нормалізації за світністю/зарядом, ні нормування площі до одиниці. Для фізичної суми потрібні погоджені коефіцієнти і перевірка моделей. X-phase-space не є підтвердженим двопіонним фоном.

Зважена сума зберігає від'ємні Weight і є лише діагностикою. Значення в кожному біні перевірено як арифметичну суму внесків, дисперсії — як суму дисперсій без урахування можливих міжканальних кореляцій. Це статистична побудова для графіків, не повна модель систематичних невизначеностей.

`combined_missing_mass.root` містить внески каналів, суми, канваси та текст cuts; `summary.json` містить перевірки, контрольні суми джерел і underflow/overflow.
