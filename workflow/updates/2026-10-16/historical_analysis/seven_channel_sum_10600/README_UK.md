# 3π при узгодженій кінематиці та тестова сума семи каналів

Новий запуск: `runs/xphsp3_Roman_007/xphsp3_Roman_007.root`, дерево h10. Джерело: гілка Bill phi-007, commit d778c567aee4c1a43230130fd83f1653fccfeb0f. Попередні шість вибірок b6025c4 збережені без змін. Старий smoke при 4,70897 ГеВ не використовується в цих графіках.

## Узгоджені налаштування

Новий input створено з фактично використаного `runs/xphsp_Roman_007/xphsp_Roman_007.inp`: змінено лише `doing_Xphasespace=1` на `3` та додано пояснювальний коментар. Усі сім inputs побайтово однакові від блоку kinematics_main до кінця файла після нормалізації перенесень рядків.

- Ebeam=10,60 ГеВ; SHMS електрон: 6,70 ГеВ/c, 13°; HMS протон: 1,10 ГеВ/c, 32°.
- Ті самі мішень, діапазони генерації, offsets і параметри моделювання.
- Radiation, energy loss і smearing вимкнено, як у попередніх шести тестах.
- ngen=1000 успішних подій. Отримано 1000 ROOT-подій із 26617 спроб.

## Перевірка 3π

Усі 1000 Weight додатні й скінченні. Min Weight=5,4661980849×10⁻¹⁸, max=4,1183926928×10⁻¹². Сума ваг до analysis cuts: 9,8823304946×10⁻¹⁰. Після cuts: 531 подія, сума ваг 4,6358720073×10⁻¹⁰. Реконструйована missing mass у записаній вибірці: 0,419264853–1,474452615 ГеВ.

Це включний режим системи π⁺π⁻π⁰ з відносним множником тричастинкового фазового простору в Weight. Індивідуальні піонні чотириімпульси не генеруються. Відсутність від’ємних ваг у цьому тесті не встановлює фізичну коректність усіх ваг/перерізів для будь-яких налаштувань.

## Що саме додано до суми

`seven_channel_sum_after.png/pdf` — сім raw-count розподілів реконструйованої missing mass після узгоджених acceptance cuts, з коефіцієнтами:

| Канал | Коефіцієнт |
|---|---:|
| omega | 1 |
| phi | 1/10 |
| rho | 2 |
| eta | 1/22,5 |
| eta-prime | 1/15 |
| legacy X-phase-space | 4 |
| новий 3π | 1, тимчасовий тестовий вибір |

Коефіцієнти перших шести збережено з останнього узгодженого raw-count аналізу. Коефіцієнт 3π не задавався керівником і потребує узгодження. Вісь Y — масштабовані тестові counts, не фізичний yield чи переріз. Нормування за Pythia або до одиничної площі НЕ застосовано. Сума після cuts: 3953,211111 старих масштабованих counts + 531 нового 3π = 4484,211111 у видимому діапазоні 0–2 ГеВ.

**Event Weight не застосовується до жодного каналу у спільній сумі.** Від’ємні ваги старих каналів залишаються на перевірці у керівника; їх не змінювали, не брали abs і не відкидали. Відповідно, raw-count форма нового 3π-внеску у цій сумі також НЕ включає тричастинковий фазовий множник, який міститься у його Weight. Weighted-форма 3π з цим множником збережена окремо: `../runs/xphsp3_Roman_007/plots/missmass_weighted.png/pdf`. Для фізичної суми ще необхідні коректні моделі ваг, узгоджена міжканальна нормалізація та контроль можливого подвійного врахування фону.

Cuts для missing-mass суми:

```text
abs(hsdelta)<8.0 && abs(hsxptar)<0.080 && abs(hsyptar)<0.035
&& ssdelta>-10.0 && ssdelta<22.0
&& abs(ssxptar)<0.040 && abs(ssyptar)<0.024
```

## Інші результати

- `seven_channel_sum_before.png/pdf`: та сама тестова сума без додаткових analysis cuts.
- `sum_six_vs_seven_after.png/pdf` та `sum_six_vs_seven_before.png/pdf`: попередня сума, доданий 3π і нова сума.
- `all_seven_Weight_no_analysis_cuts.png/pdf`: оригінальні Weight усіх семи каналів при однакових налаштуваннях; без analysis cuts та без коефіцієнтів.
- `three_pion_Weight_no_analysis_cuts.png/pdf`: окремий Weight нового каналу.
- `seven_channel_sum.root`: counts, масштабовані гістограми, суми, Weight-гістограми, полотна, метадані.
- `summary.json`: повна статистика, коефіцієнти, cuts, SHA256 джерел та перевірки.
- `../runs/xphsp3_Roman_007/plots/`: raw і weighted missing mass, Q², W, −t та acceptance-змінні до/після cuts. Логи та ROOT-події лежать на рівень вище.

Перевірено всі біни нової та старих raw-гістограм незалежним заповненням з подій, counts, масштабування похибок, суму бінів і дисперсій. Старі джерела та результати не замінено. GitHub не оновлювався.

## Відтворення

Новий симуляторний запуск уже виконано; launcher відмовляється перезаписувати наявний ROOT:

```powershell
wsl.exe -d Ubuntu -- /mnt/d/EIC/eic-shell -- /mnt/d/EIC/SIMC_RUNS/ACPOSTUMA_SIMC_GFORTRAN/run_three_pion_10600.sh
```

Повторити лише аналіз та графіки:

```powershell
wsl.exe -d Ubuntu -- /mnt/d/EIC/eic-shell -- /mnt/d/EIC/SIMC_RUNS/ACPOSTUMA_SIMC_GFORTRAN/analyze_three_pion_and_sum.sh
```

У коді `analyze_three_pion_and_sum.py` доступний аргумент `--three-pion-scale` для подальшого узгодженого коефіцієнта та `--output` для окремої папки нових графіків. Фізичний Fortran-код не змінювався.
